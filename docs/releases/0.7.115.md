# Studio 0.7.115 / ChatGPT Gateway 1.16.0 — Direct new Chat tab

Start selected rows now saves settings and calls generate-concepts with `fresh_start=true`. It no longer calls `/restart-text`. The backend cancels old local text jobs and asks the gateway to open a fresh Chat tab through `/workers/open` / `openText`; it does not send the legacy `restartText` control. The old restart-text endpoint also redirects to this path for older desktop clients.

The extension binds a new, single text worker and opens ChatGPT immediately. Prior text tabs are closed on a best-effort basis; their setup lock is not acquired or released by the new path. New single-tab prompt requests bypass the old shared input lock. JSON-to-SRT keeps its dedicated worker. The new tab is not redundantly navigated again, and an initial about:blank/pending navigation is allowed to reach the existing page-readiness wait.

The existing composer sequence remains: choose Chat / Temporary OFF, attach TXT, enter numbered SRT text, wait for Send to become enabled, and send. Video sends its duration-specific TXT for every row; image sends its TXT on the first batch and keeps the conversation. Completion, download, ownership and saved-result handling remain in place. Account limits and disconnected/disabled extensions still produce errors.

The connected extension version is now shown in the SRT to Prompt worker status and backend preparation log. A gateway paired with an older extension tells the user which version it sees instead of invoking the old restart control.

Validation: 134 targeted Node tests and 87 backend tests passed. Additional final tests for fresh pending navigation, direct submission, mode recovery and SRT tabs passed after removing redundant navigation. Direct-path tests poison the old setup lock and verify both TXT-per-video-row and TXT-once-per-image-conversation behavior. Syntax checks passed. These use simulated Chrome/ChatGPT surfaces; live Windows provider generation was not run.

Install: close Studio, replace application source, reload Flowkit ChatGPT Gateway from this version's extensions/chatgpt folder at chrome://extensions, verify version 1.16.0, then reopen Studio. The Google Flow extension is unchanged. Preserve existing databases, .env and output folders.
