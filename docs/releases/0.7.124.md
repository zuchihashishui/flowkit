# Studio 0.7.124 — Subtitles off by default

- **Subtitles in output video** appears at the top of Merge Audio + SRT + Media, outside the collapsible Sources & render settings panel.
- **No subtitles (default)**: no burned text and no embedded subtitle track. SRT continues to control scene timing.
- **Burn into video**: permanently visible text. The subtitle font control appears for this option.
- **Selectable subtitle track**: the player can show/hide the embedded track.
- On first opening after this update, each video’s old Merge draft is reset to Off once, including inherited legacy Burn defaults. Later explicit choices are saved separately for each video. Existing queued/completed jobs keep their original settings; create a new render to change subtitles. Applying video defaults explicitly can still restore previously saved project/video settings.
- New project defaults and omitted unscoped API defaults also use Off.
- Timeline review states the selected subtitle mode before rendering. Project/video source loading and output paths from v0.7.123 are retained.

## Cập nhật

Đóng Studio/backend, chép đè nội dung thư mục `flowkit` vào bản hiện tại, giữ nguyên database và `output`, rồi mở lại. Không cần cài lại môi trường hoặc extension. Chọn project/video → Merge Audio + SRT + Media → kiểm tra **No subtitles (default)** → Check files & preview → Render MP4.

Video cũ đã chèn chữ cố định không tự mất chữ; cần render lại từ nguồn. Job đang chờ hoặc resume cũng giữ lựa chọn đã lưu trước đó.
