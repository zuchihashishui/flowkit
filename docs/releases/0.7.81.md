# Studio v0.7.81

Scene Board image jobs now copy verified downloads into output/scene_images/<video-id>/ using the original scene ordinal: 001.png, 002.png, etc. Actual PNG/JPG/WebP/AVIF extensions are preserved; multiple returned images use 001_02, etc. Original files remain in output/desktop/<job-id> for previews, recovery and previous generation history.

The Scene Board displays the exact folder path. Collect saved images copies existing completed current scene images without submitting generation requests. Jobs from other videos and outdated prompts are excluded. The newest completed matching job wins even if an older generation completes later. A private index tracks numbered copies, allowing obsolete copied extensions for the same scene to be removed while keeping job originals. Existing copies of other scenes are retained.

Files are copied through temporary files and atomic replacement. Copy failures retain the completed job and original file, show an error and can be retried with Collect saved images; they do not trigger new paid generation. The configured desktop export folder continues its existing separate per-job exports.

Submission settings are unchanged: one prompt per Flow request, up to three active desktop image/video jobs combined, with a default minimum three-second generation interval. Cooldown or occupied workers can make waits longer; the minimum interval can be overridden by FLOW_GENERATION_MIN_INTERVAL_S.

Validation: 71 Python tests and 19 UI tests passed. Added coverage for automatic collection, saved-result collection, original numbering/formats, newer completed results, video separation, stale prompts and copy failure recovery. Chrome/Flow generation remains mocked. Restart Studio/backend after updating; extensions are unchanged.
