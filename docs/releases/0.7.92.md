# Studio 0.7.92

SRT to Prompt exposes independent TXT upload buttons and filenames for Image, Video 4s, Video 6s, Video 8s and Video 10s. The row selector now offers Image or Video. Video resolves to the smallest supported duration covering the SRT scene; scenes above 10 seconds use 10s and show a warning. The backend recalculates from stored timestamps, including previously saved explicit video choices. Missing required instructions block submission with the scene number and missing file type. Original TXT contents stay unchanged. Existing grouping, first-message attachment and ZIP processing remain intact.

Restart Studio. No extension update is needed.
