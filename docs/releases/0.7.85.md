# Studio v0.7.85 — Image and video generation in Scene Board

Prompt to Image and Prompt to Video now share the Scene Board table. Their
separate menus and forms are removed. Project stage links and SRT to Prompt
handoffs open Scene Board, preserving selected scenes.

- Each row defaults to Image. Choose Video in its Create column when needed.
  Choices are saved locally per project/video and scene.
- Select rows and click Generate selected scenes. A mixed selection submits
  separate image and video groups using each scene’s matching saved prompt.
- Image Model and Aspect Ratio remain available. Video duration defaults to
  fitting SRT timing (4/6/8/10 seconds), with manual duration choices available.
- Missing or outdated prompts identify the affected rows. Both groups pass
  preflight before either is submitted. Partial submission errors report how
  many jobs were confirmed and direct users to Jobs & downloads before retrying.
- Active jobs are always skipped. Completed results are kept unless Regenerate
  completed selected scenes is explicitly checked; original files remain saved.
- Existing job history, download recovery, previews, exports and retry controls
  remain inside Scene Board. Actions support up to 200 selected scenes.

Update the full source ZIP and restart Studio. No extension reload is needed.

Validation: desktop JavaScript syntax checks and 77 UI tests passed, including
mixed image/video groups, defaults and persistence, missing prompts, preflight
failure, partial submission, duration, regeneration and production handoffs.
Tests use DOM/API mocks; live Google Flow generation was not exercised.
