# Studio 0.7.131 — GPT-5.6 Sol and DOM file clicks

The user verified that `.click()` downloads the ZIP from the GPT-5.6 Sol file
reference layout. This release restores DOM `.click()` for ZIP links and
preview Download controls and removes debugger code and permission. SRT's
existing download handling is retained.

SRT to Prompt now offers GPT-5.6 Sol as the default ChatGPT model in the Model
field. The field accepts another exact model name or `auto` to keep the page
model. The choice is saved per video and copied into queued jobs. Both video
text and image ZIP batches pass that model to the bridge instead of forcing
`auto`. Gemini integration is not implemented by this release.

The model picker recognizes the provided Instant trigger's
`ModelPickerTriggerLabel` / `ModelPickerTriggerModelGroup` markup and clicks
its enclosing button when present. It selects an exact enabled model option
and verifies the resulting model before sending. An absent, ambiguous or
unverified option stops submission rather than using another model silently.
Only trigger markup was supplied; a different dropdown option layout may need
additional support after inspecting its actual markup.

Reload ChatGPT Bridge as 1.16.12 and refresh existing ChatGPT tabs. In SRT to
Prompt choose GPT-5.6 Sol and apply settings before starting a new run. Previously
queued requests retain their saved payload. Failed requests are not retried
automatically. Chrome download completion is still required before saving ZIP
results. Console success on the supplied layout is user-confirmed; the complete
updated extension flow has not been verified in the user's Windows Chrome.
