# Studio 0.7.115 ZIP markup fix / ChatGPT extension 1.16.2

This patch is based on the restored 0.7.115 source. It does not restore the withdrawn 0.7.116 Start/scheduler changes. Studio and gateway remain 0.7.115; only the ChatGPT extension version changes.

The supplied response uses a DilResponseRoot with data-dil-message-id and an interactive span with role=link, data-d-component=pressable, and aria-label="Open Tải image_prompts.zip". The old link selector already supported role=link, but the answer selector did not recognize that response root, and file completion evidence required the older data-file-reference markup.

The extension now recognizes DIL assistant roots, deduplicates nested roots, tracks their stable message IDs, and accepts an enabled DIL file link as file-output completion evidence after streaming stops and four stable polls. Existing TXT/SRT sending and native Chrome download handling remain unchanged. Hidden, disabled, busy, old and ambiguous links are not clicked.

Validation: the new markup reproduced 12 failures before the change. After the change, 117 targeted Node tests passed, including standalone and nested DIL responses, the original Work markup, old-message remounting, both Chat/Work modes, TXT reuse, send behavior and direct tab start. Syntax and diff checks passed. DOM and Chrome download events were simulated; a live provider download was not executed.

Install: replace extensions/chatgpt with this version, reload the extension at chrome://extensions and refresh existing ChatGPT tabs to load the updated content script. Verify extension version 1.16.2. No backend/database changes are required.
