# Studio 0.7.56 — immediate SRT window
Select a project and video, then open **SRT**. Studio opens a separate ChatGPT window, focuses and binds its tab, and selects Work automatically.
Choose a JSON source and review your prompt. **Create SRT** validates the source, then attaches the prompt and indexed JSON in the prepared tab. Opening the menu alone does not submit a prompt.
The dedicated SRT worker remains separate from the three Text to Prompt workers. Busy or review-required jobs cannot be replaced. Stale preparation tokens cannot send to another tab. Existing source timing, boundary validation and save acknowledgment are preserved.

## Upgrade
Replace the complete source and restart Studio, backend and ChatGPT gateway. Reload **extensions/chatgpt** in Chrome (version 1.9.1). Other extensions do not require an update. Existing jobs and audio are retained.

## Verification
Automated tests cover separate window creation, focus and binding, prepared-tab reuse, stale-token rejection, Work options and JSON attachment forwarding. Live ChatGPT generation requires verification in the user's signed-in Chrome session.
