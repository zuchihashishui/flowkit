# Studio v0.7.76

Scene Board can now generate images directly from selected scenes with current image prompts. Choose an image model from the backend catalog and landscape 16:9 or portrait 9:16. Settings are remembered separately for each video, initially using video production defaults.

Completed and active images are skipped. Generation requires confirmation, production preflight, saved settings, and unchanged video ownership. Retry retains the original job settings and can resume remote downloads. Prompt to Image remains available for standalone prompts and its existing batch modes.

Validation: 17 Scene Board and workflow UI tests passed, including generation payloads, per-video settings, missing prompts, blocked preflight, and video changes. Live image generation was not exercised. ChatGPT Bridge remains 1.12.3.
