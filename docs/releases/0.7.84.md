# Studio v0.7.84 — Scene Board jobs and downloads

Queue & Downloads is now part of Scene Board. Its separate sidebar entry and
page are removed. Use Jobs & downloads at the top of Scene Board to jump to
media job history below the scene table.

Preserved controls:

- Current-video, project-wide and unassigned-project job filters; search, media
  type and status filters; queued/running/completed/error totals.
- Google Flow activity, submission interval, active slots and cooldown status.
- Pause/resume media processing across all projects (explicitly labeled),
  cancel queued jobs, and resume downloading saved remote results.
- Per-job details/errors, existing-file exports and bulk filtered exports.
- Completed job previews inside Scene Board; closing details, changing video
  or leaving the page prevents a late preview from reopening it.

Each scene's current media jobs now have Job details links in Activity. Saved
images/clips also have Export files beside their preview buttons. Scene rows
refresh when media job state changes, including download recovery from history.
Project recovery links now open the matching job in Scene Board.

Other production menus and automatic export settings remain available. Existing
jobs, files, backend APIs, generation limits and extension code are unchanged.
Update the full source ZIP and restart Studio. No extension reload is needed.

Validation uses DOM/API mocks; no live Flow generation or paid requests.

Checks passed: desktop JavaScript syntax validation and 63 UI tests covering
navigation, scene actions, job recovery/cancellation, export, preview cleanup,
Flow status, project/video isolation and existing production handoffs.
