# Studio 0.7.134 — continue after selecting the model

At the user's request, Bridge 1.16.15 no longer waits for the model label to
confirm selection and no longer rechecks model/effort before attaching files
or sending. Once the requested enabled option is clicked, it continues after
a short UI settling delay. The Instant submenu selection remains in place.

Missing, disabled or ambiguous options still report selection errors; this
change removes post-selection verification rather than skipping model selection.
Tests cover unchanged labels and a label reset before Send: neither blocks
submission. ZIP downloads continue using DOM click without debugger permission.

Reload the extension as 1.16.15 and refresh ChatGPT tabs before a new run.
