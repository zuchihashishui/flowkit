# Studio 0.7.65 / ChatGPT Bridge 1.11.2

Sửa lỗi Start selected rows hiện bảng “Image prompts · Action required” chỉ vì request ChatGPT cũ còn trạng thái cần kiểm tra.

Text to Prompt dùng bước chuẩn bị tab riêng như JSON → SRT. Nút Start selected rows và Retry cho ChatGPT không gọi hộp preflight tổng quát trước bước này. Các kiểm tra dữ liệu, project/video và cài đặt chưa lưu vẫn giữ nguyên; backend/gateway vẫn kiểm tra kết nối và trạng thái tài khoản.

Bridge tự mở và bind đủ ba tab. Với worker lỗi đã ngừng chạy, bridge giữ lại tab cũ cùng câu trả lời, mở tab thay thế và chỉ giải phóng reservation lỗi khi chuẩn bị thành công. Không đánh dấu lịch sử request cũ là đã kiểm tra, không tự gửi lại job cũ. Dòng lỗi chỉ chạy lại khi người dùng chọn Retry. Worker đang chạy hoặc chờ lưu không bị thay thế; tab Work của JSON → SRT vẫn độc lập. Giới hạn tài khoản vẫn yêu cầu chờ và resume sau khi hết giới hạn.

Text to Prompt vẫn dùng Chat, Temporary bật; TXT gửi một lần trên mỗi hội thoại, các lượt sau chỉ gửi mục SRT. JSON → SRT vẫn dùng một tab Work, Temporary tắt.

Cập nhật Studio/backend/gateway lên 0.7.65, reload extensions/chatgpt trong chrome://extensions và xác nhận Bridge 1.11.2. Làm mới các tab cũ, khởi động lại Studio, rồi nhấn Start selected rows.
