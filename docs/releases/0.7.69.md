# Studio 0.7.69

## Nguyên nhân

Click menu SRT trong desktop/ui/srt.js gọi prepareTab() ngay khi vào trang. Hàm này POST /api/srt/prepare; backend chuyển qua gateway tới extension để mở một cửa sổ ChatGPT, bind tab và chọn Work. Vì lời gọi nằm trong sự kiện điều hướng, không cần chọn JSON hoặc nhấn Create SRT vẫn mở tab. Handoff Use for SRT cũng đi qua cùng sự kiện.

## Sửa

Bỏ prepareTab() khỏi sự kiện click menu SRT. Vào trang SRT và chuyển nguồn sang SRT chỉ tải lại danh sách nguồn, job và trạng thái. Cập nhật phần hướng dẫn trong UI.

Create SRT vẫn kiểm tra đầu vào rồi mở/bind tab Work và gửi yêu cầu như trước. Nút Open / select SRT window vẫn cho phép chủ động chuẩn bị tab. Bản này chỉ sửa Studio UI; extension giữ phiên bản 1.11.5.

## Kiểm tra

Hai kiểm thử hành vi đã tái hiện lỗi trước khi sửa: mở menu SRT và handoff nguồn đều gửi POST chuẩn bị tab. Sau sửa kiểm tra các thao tác này chỉ GET dữ liệu, việc chọn JSON không mở tab, và Create SRT vẫn chuẩn bị trước khi gửi job. 18 kiểm thử UI liên quan và kiểm tra cú pháp/diff đều đạt. Các kiểm thử UI chạy trong môi trường mô phỏng; chưa chạy Electron trên máy người dùng.

## Cập nhật

Đóng và mở lại Studio bằng source v0.7.69. Không cần thay extension nếu đang dùng Bridge 1.11.5.
