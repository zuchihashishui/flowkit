# Studio 0.7.110 — Table-based management workspace

## Changes

- Shared table controls: numeric sorting, text search, column visibility and resizing, saved column preferences, fixed headers, compact cells and scrollable tables without scene pagination.
- SRT to Prompt separates selection, scene number, SRT timing, narration, Image/Video, matching instructions/duration, prompt, status and actions. Filtered select-all reflects partial selection. Keyed row updates retain unchanged rows, focus and scroll. Row choices have explicit Apply/Discard feedback.
- Prompt instructions are five independent table rows (Image and Video 4/6/8/10s), with upload/replace, view/edit and remove-from-configuration. Editing opens in a side panel; removal is saved explicitly through Apply.
- Prompt to Media keeps model/aspect settings and shows their next-generation values per row. Other media types are collapsed, with current results, retry and job logs retained. Header selection and focus are refreshed consistently.
- Project uses a table and a settings side panel. A single visible video table shows all eight production stages, selection, edit, folder access and next-step actions. The existing video selector remains the shared workflow context. Creation, legacy scene tools, history and connection details are folded.
- WhisperX, JSON to SRT, render history and media jobs/downloads use tables. Existing narration/chunk tables use the same controls. Long stage setup forms are collapsible. Existing preview, save, cancel and retry actions retain their API handlers.
- Scene/prompt and media-job details use right-side panels. Closing the Project/Video settings panel keeps its draft; existing save/reload and dirty-state guards still apply.
- Empty projects/videos can be deleted from their tables. Electron accepts DELETE only on exact project/video record routes. The backend refuses deletion of projects containing videos and videos containing scripts/scenes/media jobs, in addition to existing saved-source/job checks.
- Corrected obsolete Chat/Work and video TXT wording; removed duplicate ElevenLabs model input ID.

## Compatibility

Restart Studio and its backend after updating the full source. ChatGPT Bridge remains 1.15.0 and Google Flow Bridge remains 0.6.4. This release does not change provider dispatch, ChatGPT video/image phases, batching, downloads or model mappings. Scene numbers and saved file mappings are unchanged.

## Validation

- UI/IPC regression suite covering tables, 1,000 keyed rows, project/video context, prompt/media submission, retry, preview and settings.
- Backend tests cover refusal to delete owned records and successful deletion of empty records.
- JavaScript syntax checks and ZIP integrity check.
- The existing `test_other_videos_history_limit_cannot_hide_old_sources` fixture fails on its old SRT output path; the identical failure was reproduced from the unmodified 0.7.109 ZIP.
- Windows Electron visual rendering and live ChatGPT/Flow generation were not available in this environment. UI checks use jsdom, not a live provider session.
