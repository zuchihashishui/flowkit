# Studio 0.7.93

Add First SRT rows as Video, default 15, range 0–1000, saved per video. The first N rows in original SRT order use video instructions selected automatically by duration; remaining rows use image instructions. Individual row overrides are retained until the count changes. Changing the count resets those overrides so the table reflects the new range. Zero selects images for all rows; a count above the number of scenes selects every scene as Video. Queued payloads remain unchanged.

Restart Studio; no extension update required.
