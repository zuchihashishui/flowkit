# Studio 0.7.146 — Read types from populated SRT documents

Fix the incomplete Type inheritance in 0.7.145. For a video with imported SRT scenes, the storyboard API returns prompt_options inside document; top-level prompt_options is used only when there is no document. Prompt to Media now follows the same document-first lookup as SRT to Prompt.

Updated the inherited-Type tests to use the populated-document response shape. Added a regression for document-first precedence and recovery from cached Image defaults created by 0.7.145. All 28 scene-board UI tests passed. Existing prompts, media files and queued jobs are unchanged.
