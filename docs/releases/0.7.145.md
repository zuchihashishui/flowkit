# Studio 0.7.145 — Carry SRT scene types into Prompt to Media

Prompt to Media now reads the saved SRT to Prompt Type for each scene, including the first-video-rows default and explicit image/video choices. Previously its independent Create selector defaulted every row to Image. Video generation continues to use duration_mode=srt for 4s/6s/8s/10s clips.

Explicit Create overrides remain scoped to their video and survive refresh. A saved upstream Type change clears that scene’s override. Old default Image selections are not treated as explicit overrides. Existing jobs and generated files remain unchanged.

Validation: 27 scene-board UI tests passed, including inherited Type display, mixed request grouping, SRT-based duration, manual overrides, refresh, and video isolation. No live Google Flow generation was submitted.
