# Studio 0.7.66 / ChatGPT Bridge 1.11.3

## TXT là file đính kèm

Lượt đầu trong mỗi tab Temporary Chat: tải lên file UTF-8 prompt-instructions.txt từ nội dung TXT đã lưu và chỉ nhập câu SRT vào ô chat. Đợi file tải lên hoàn tất rồi mới gửi. Các lượt sau trong cùng hội thoại chỉ gửi câu SRT, không đính kèm lại TXT. Nếu hội thoại bị mất hoặc bắt đầu lượt chạy mới, file được đính kèm lại trên tab đó. Ba tab có ngữ cảnh riêng nên mỗi tab cần file một lần.

Không dán toàn bộ TXT vào tin nhắn nữa. JSON → SRT vẫn đính kèm JSON trên một tab Work riêng, Temporary tắt. Tăng thời gian chờ vận chuyển cho phiên TXT để bao gồm bước upload.

## Nhận câu trả lời Temporary Chat

DOM được cung cấp có nội dung assistant trong data-markdown-text-style nhưng toolbar Copy / Rate response / Regenerate response nằm ngoài search unit, cạnh khung của cả lượt. Bridge nhận biết đúng khung này, chỉ trong phạm vi một câu trả lời; vẫn chờ hết trạng thái generating/busy và nội dung ổn định trước khi trả kết quả. Không coi toolbar của lượt trước, nút ẩn hoặc Copy trong code block là bằng chứng đã hoàn tất.

## Cập nhật

Đóng Studio và backend/gateway, cập nhật mã nguồn, reload extensions/chatgpt và xác nhận Bridge 1.11.3, làm mới các tab cũ rồi khởi động lại Studio. Với dòng đã kẹt Processing từ bản cũ, kiểm tra câu trả lời còn trong tab trước khi chọn Retry ở bản mới; không tự gửi lại yêu cầu cũ. Dữ liệu đã lưu được giữ nguyên.

Regression tests use the supplied Temporary Chat HTML locally and a fixture with user text removed in the repository. They cover extracting completed responses, a second turn after the first response, exactly one TXT upload per used conversation, Unicode file content, streaming/busy/hidden/previous-turn/code-copy decoys, and upload readiness/failure. Existing JSON/SRT tests remain included. No live signed-in ChatGPT run was performed.
