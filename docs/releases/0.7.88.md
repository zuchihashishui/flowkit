# Studio v0.7.88 — Remove Word JSON preflight popup

WhisperX no longer shows the Word JSON / Action required checklist dialog.
Successful checks continue directly to job creation. Failed checks show their
specific error inline through the existing WhisperX message area. Source,
project/video ownership and environment checks still run before queuing.

Other stages retain their existing UI. This change removes the popup; an
unsupported Windows subprocess loop still needs the updated backend launcher
from v0.7.87 and a full backend restart.

Update the source and restart Studio. No extension update is needed.
