The user clarified the actual sequence: click Instant in the composer, then
Instant in the opened menu, then choose GPT-5.6 Sol from the model list.

not yet visible, it opens the exact Instant entry in the owned menu once,

requested model and retains verification before sending. Existing direct model
menus and reasoning-effort selection remain supported. No prompts are sent
when the requested model cannot be found or verified.

required to expose GPT-5.6 Sol, plus existing missing/disabled/ambiguous choices.
