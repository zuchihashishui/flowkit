# Studio 0.7.57
Create SRT submits directly through its dedicated prepared Work tab without the global production preflight modal. Historical ChatGPT request records no longer block creation through that modal.

The standalone ChatGPT navigation entry, page and its loaded scripts are removed. Connection diagnostics remain in Settings; SRT and Text to Prompt retain their bridge functionality. SRT's connection button now opens Settings.

Source ownership, attachment handling, response capture and saving remain intact. An actually running SRT request is still allowed to finish before another request uses its worker. No old request is automatically resent or deleted.

Update the complete source and restart Studio. ChatGPT Bridge remains 1.9.1; reload it if upgrading from a version older than 0.7.56.
