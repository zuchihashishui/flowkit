# Flowkit Studio 0.7.125 — Delete projects and videos with related data

Projects and videos no longer have to be empty before deletion from Studio.
The confirmation explicitly covers all child videos (for a project), scripts,
scenes, concepts, prompt runs, source records, job history and managed output
files. Both video tables share the same deletion action.

The desktop sends DELETE with `?cascade=true`. Legacy API calls without that
explicit flag retain the old empty-record restrictions. Nothing is deleted
until the user confirms the UI prompt.

Main database rows and the media, ElevenLabs, WhisperX, SRT and Assembly stores
are cleaned together in one attached-database transaction. Shared characters
and global settings remain reusable; project links and local settings are
removed. Other projects, sibling videos and unassigned sources are preserved.
Jobs that are queued, running, downloading, cancelling or still merging must
finish or be stopped before deletion. Dependencies from another scope block
deletion with an explanatory message instead of breaking their references.

The cleanup covers identity-scoped project/video folders and recorded legacy
job/import/prompt files. It never calls a remote Google Flow, ChatGPT or
ElevenLabs delete API, nor removes original files outside managed storage.
Legacy project output directories are recognized by their `meta.json` project
identity, not just a matching display name.

Files are staged before database deletion and restored on an ordinary rollback.
A durable journal restores interrupted, uncommitted file moves on startup;
committed cleanup blocked by a file lock is reported and retried on restart.
The file organizer is locked during deletion to prevent late snapshot copies.

After successful deletion the selected workspace, video list and job history
refresh. Rejected deletion keeps the current selection visible.

Validation: 97 backend tests passed (deletion, ownership, project workspace and
ElevenLabs); 34 desktop UI/IPC tests passed; desktop JavaScript syntax checks
passed. Coverage includes sibling/project isolation, managed file deletion,
active jobs, cross-scope references, file locks, database rollback and restart
recovery. An existing UI test's old “Scene Board” heading expectation was
updated to the existing “Prompt to Media” label. Tests use local temporary
databases/files and mocked Electron UI, not the user's Windows installation.

Update: close Studio and its backend, extract this full release over the
installation, then reopen Studio. No ChatGPT/Google Flow extension reload is
needed for this change.
