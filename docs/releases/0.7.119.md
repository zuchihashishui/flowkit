# Studio 0.7.119 — recognize supplied DIL response toolbar

ChatGPT Bridge 1.16.5 links the supplied Copy / Rate response / Regenerate response toolbar to its current DIL answer even when the toolbar is beside the answer root or its assistant wrapper. Ancestor search is bounded, stops before shared conversation containers containing another assistant answer, and ignores code/user controls and hidden buttons.

The previous responseScope returned early without searching sibling toolbars for standalone DIL roots and nested assistant wrappers. Existing ready-file fallback remains; this change repairs toolbar evidence and does not prove that this defect alone caused the user's runtime ZIP failure.

Validation: retained the user's actual toolbar HTML as a regression fixture. Before the fix, three of eight new cases failed; afterward all eight pass, including current text/ZIP responses, nested wrappers, old or hidden toolbars, code Copy, busy answers and active generation. All 148 targeted completion, TXT, ZIP, bridge and direct-start tests pass. Tests simulate browser behavior; no live Windows session was available.

Reload extensions/chatgpt as version 1.16.5, refresh existing ChatGPT tabs and restart Studio after updating.
