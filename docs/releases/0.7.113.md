# Studio 0.7.113 / ChatGPT Bridge 1.15.1 — Start worker restart conflict

The reported HTTP 409 occurs before prompt submission, in `/workers/restart`. The supplied access-log lines do not include the gateway's error body, so they do not establish which rejection occurred on the user's machine.

Two concrete defects were found and repaired:

- Automatic idle-tab cleanup and an explicit Start could overlap, causing an immediate 409. Backend cleanup now shares the restart lock. The gateway reserves restart, waits up to 30 seconds for an existing cleanup/inspection to finish, and shares one restart between overlapping callers. New text submissions/preparations cannot race into that interval. Actual tab stopping still requires extension acknowledgment; timeouts and extension failures remain visible errors.
- The extension announced `inspecting=true` while clearing idle tabs, then released its configuration flag without announcing the new state. Cleanup and manual configuration now announce the released state, avoiding a stale gateway inspection flag.

Failures now log the gateway HTTP status, code and reason, plus the selected video ID, into the backend log. The UI retains the backend error detail and reports that it is waiting for cleanup. This does not replay prompt submissions or reset account rate limits. Dedicated JSON-to-SRT workers and saved results are preserved.

Install: close Studio, replace source, reload the **Flowkit ChatGPT Gateway** extension from `extensions/chatgpt` at `chrome://extensions` (version **1.15.1**), then reopen Studio. Restart any separately launched old ChatGPT gateway too. No Google Flow extension update is required.

Validation: 26 gateway tests and 86 backend tests passed. The broader desktop/ChatGPT run passed 222 of 226 tests, including the restart, TXT/video/image, UI and route tests. Four existing failures in `chatgpt-panel.test.cjs` and `chatgpt-workers.test.cjs` reproduce on the unmodified 0.7.112 ZIP (stale attachment label and worker test stubs); they were not changed by this fix. Syntax checks passed. Live Windows Chrome/Electron behavior was not exercised.
