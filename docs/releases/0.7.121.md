# Studio 0.7.121 — Chrome input for DIL ZIP links

ChatGPT Bridge 1.16.7 replaces synthetic page events on DIL Pressable output links with Chrome mouse input through the debugger API. The supplied markup and Activity log establish link detection, but do not establish successful activation by page events.

The bridge attaches only to the active job tab, focuses it, resolves the same response and file again, scrolls it into view and checks the hit target before sending one mouse press/release. It detaches afterwards. Cancelled requests, covered links and debugger failures return explicit errors. The download listener is installed before input; success still requires a matching completed Chrome download.

The extension now requires the debugger permission. Reload extensions/chatgpt and accept the permission if Chrome requests it; Chrome may display a debugging banner during activation. Refresh existing ChatGPT tabs. Studio, gateway and bridge should be updated together.

Batch sizes, prompt attachments, response completion and project/video storage are unchanged. Automated tests cover coordinates, wrong request tokens, covered links, native input order, download completion and debugger failures. These are simulated tests; downloading in the user's Windows Chrome has not been verified here.
