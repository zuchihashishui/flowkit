# Studio 0.7.144 — Slow short video clips to fit scenes

Merge Audio + SRT + Media defaults to Slow down to fit for short clips. A 10-second clip in a 12-second scene plays at 0.833× speed. The same rule applies to any shorter clip, including 4s, 6s and 8s sources. Longer clips are trimmed at normal speed.

Hold last frame and Loop clip remain selectable and persist per video. Existing form drafts switch to the new default once; already queued renders keep their saved options.

Rendering stretches video timestamps to the scene duration, enforces the exact scene frame count and keeps the narration and SRT unchanged. Clip audio stays muted. Preview and file checks report the slowdown ratio. The CLI also accepts clip_end=slow.

Validation: real FFmpeg renders cover slowdown, trimming, freeze, loop, audio isolation and scene boundaries, including 10s → 12s. UI tests cover the default and persistence of all three options.
