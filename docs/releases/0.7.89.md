# Studio v0.7.89 — SRT prompt modes, batch size and per-row instructions

- Choose ChatGPT Web - 1 Work tab or ChatGPT Web - 1 Chat tab. Both use one
  sequential worker with Temporary OFF; JSON to SRT keeps its separate Work tab.
- Rows per message defaults to 10 and accepts integers from 1 through 20.
- Five instruction slots: prompt_instructions_image, prompt_instructions_video_4s,
  prompt_instructions_video_6s, prompt_instructions_video_8s and
  prompt_instructions_video-10s. Select a slot, choose its TXT and save settings.
  Stored original text is preserved; output rules are appended only to the copy
  attached to ChatGPT. Existing instruction TXT becomes the Image default.
- Each SRT row defaults to Image, with a dropdown to choose any video duration
  instruction. Instruction files, row choices, mode and batch size save per video.
- Selected rows are grouped by instruction type. Each type starts a fresh
  conversation in the same bound tab and attaches its own TXT once. Later groups
  for that type send only numbered SRT rows. A lost conversation reattaches TXT.
- All numbered TXT files from a run share one output directory across types.
  Source ZIPs are retained. ZIP completion still waits up to 30 minutes before
  validation, storage and the next group. Original row numbers remain unchanged.
- Missing selected instruction files block the entire run before jobs are queued.
  Queued jobs retain their original instruction snapshot if settings change.
  Retry uses the selected row type. CLI provider behavior remains available.

Update the complete source, restart Studio and the gateway, reload
extensions/chatgpt (Bridge 1.13.0), then refresh existing ChatGPT tabs.
Google Flow Bridge does not change.

Validation: 97 backend tests, 79 UI/extension tests and 22 gateway tests passed,
plus desktop JavaScript syntax checks. Tests cover numbered ZIPs, both composer
modes, continuation without repeated TXT attachment, row ownership, instruction
persistence, missing files, configurable groups and frozen queued inputs.
No live ChatGPT submission was performed here.
