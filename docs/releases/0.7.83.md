# Studio v0.7.83 — Project/video folders

The backend maintains a browsable copy of each video's saved files under
`output/projects/<project-name--identity>/<video-title--identity>/`.
Names are sanitized for Windows and include a stable identity suffix. Videos
with identical titles stay separate. Renaming a title does not move existing
folders; project.json/video.json always contain the current names and IDs.

| Folder/file within a video | Contents |
| --- | --- |
| elevenlabs/ | Source text, audio chunks, merged audio and job details, per job |
| whisperx/ | Transcripts, split JSON and worker logs, per job; imported JSON |
| srt/ | Original imported source, saved SRT job versions and current scenes.srt |
| audio/ | Imported narration audio |
| prompts/image/, prompts/video/ | Current scene prompts: 001.txt, 002.txt, etc. |
| prompts/runs/ | Saved TXT/ZIP history, separated by run |
| images/, videos/ | Current scene images/clips: 001.png, 002.jpg, etc. |
| exports/ | Completed assembled videos, separated by job |
| scenes.csv | Exact row → segment ID → media job and filename mapping |
| files.json | Original source locations and any missing-file/copy warnings |

Project has Open project folder and Open video folder on every video card.
Scene Board also has Open video folder. Opening a video folder refreshes its
copies first and shows any warnings. A background sweep repeats after a
15-second pause while the backend runs; it does not submit generation jobs.

Existing assigned outputs are collected without regeneration. Original paths,
database references and job files are retained. These additional copies use
extra disk space. Active jobs are skipped until they leave active processing;
missing source files are reported. Unassigned resources are never guessed into
a video: use Project's existing source-chain assignment first.

The current numbered views follow existing Scene Board eligibility checks,
including source revisions and exact video/segment/concept IDs. Regeneration
can replace the current numbered copy; previous original job files remain.
Numbers are internal scene ordinals, not arbitrary original SRT cue labels.

Install the full ZIP and restart Studio/backend. No extension update is needed.
Folder organization and UI actions are tested with local fixtures; no paid
ElevenLabs/Google Flow generation or live Windows Explorer session was used.
