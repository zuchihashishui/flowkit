# Studio 0.7.135 — Flow activity for the selected video

The Google Flow activity panel now requests and displays only media jobs whose
project_id and video_id both match the current selection. Completed, failed,
queued and active counts use that same scope. Voice jobs remain excluded.

No selection displays a selection prompt rather than global counts. Changing
scope clears the old list and late responses for the previous scope are ignored.
The title now says Selected video. Active counts are labelled as jobs in this
video, rather than implying a separate three-slot allowance for each video.
Queue pause, actual concurrency and submit interval remain application-wide.

The endpoint accepts paired project_id/video_id query parameters; unscoped
callers retain the existing global response. Incomplete scope is rejected.
No extension update is required; ChatGPT Bridge remains 1.16.15.
