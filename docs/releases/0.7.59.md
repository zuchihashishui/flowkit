# Studio 0.7.59 / ChatGPT Bridge 1.9.3
Fixes attachment-to-send readiness detection. The extension considers all matching visible Send controls, ignores disabled duplicates, and checks loading indicators on the attached file rather than unrelated composer spinners. The filename can also be identified through a labelled removal control or data-filename.

After upload readiness is stable for two polls (about one second), the extension clicks Send once. If the control becomes disabled again, it waits up to 120 seconds instead of failing after three seconds. Upload errors or a missing attachment still prevent sending.

Reload extensions/chatgpt in Chrome (1.9.3). Restart Studio when replacing the full source. Refresh existing ChatGPT pages, or use the new SRT window.

Automated DOM tests cover delayed Send activation, disabled duplicate controls, unrelated spinners, a genuinely busy file, upload errors, missing files and one-time submission. Live ChatGPT verification remains necessary in the user's browser.
