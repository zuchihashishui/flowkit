# Studio 0.7.140 — GPT-5.6 Sol video ZIP output

New GPT-5.6 Sol jobs append the shared `template_zip_file.txt` to both image and video instructions:

- `template_image_prompt.txt` + `template_zip_file.txt`
- `template_video_4s_prompt.txt` + `template_zip_file.txt`
- `template_video_6s_prompt.txt` + `template_zip_file.txt`
- `template_video_8s_prompt.txt` + `template_zip_file.txt`
- `template_video_10s_prompt.txt` + `template_zip_file.txt`

Video continues to submit one scene at a time, now downloading and validating a ZIP containing its numbered TXT. Saved video prompts preserve existing image prompts. Images wait for video jobs to finish and retain their existing batch size. Instructions remain separate on disk and are combined for submission. The existing extension ZIP protocol is reused; instructions are attached at conversation start or when the combined template changes.

This rule applies only to GPT-5.6 Sol. Other model video jobs keep their existing text-output behavior. Jobs already queued retain their saved options; start new jobs to use the updated rule.

Restart Studio after updating. No Chrome extension update is required.
