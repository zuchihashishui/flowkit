# Studio 0.7.91 — Project/video output storage

New project-owned jobs save originals below `output/projects/<project>/<video>/`:

- `elevenlabs/<job>/`: chunks and merged narration.
- `whisperx/<job>/`: transcript JSON, splits and logs.
- `srt/<job>/`: SRT and timing reports; `srt/imports/` holds imported JSON.
- `text_prompts/<run>/`: numbered TXT files and downloaded ZIPs.
- `scene_board/image/<job>/` and `scene_board/video/<job>/`: original generated media and versions.
- `images/001.png`, `videos/001.mp4`: current scene copies, updated by the organizer.
- `audio/`: imported narration; `scenes.csv` maps scene IDs to current media.

Folder names include stable identity suffixes so equal titles do not collide. Renaming a project or video does not change existing folder paths. Stored service paths remain pinned when resource ownership is subsequently changed.

Existing jobs and imports keep their original locations and remain readable; the organizer continues copying their owned outputs into the video folder. Unassigned legacy resources remain unassigned. No files are deleted or guessed into the selected project. The organizer updates every 15 seconds and when opening the video folder.

Restart Studio/backend after installing. No extension change is required from 0.7.90. Tested with local backend regressions; no live paid generation was run.
