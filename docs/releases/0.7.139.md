# Studio 0.7.139 — Project prompt instructions

All videos in a project can use one shared instruction set in:
`output/projects/<project>/prompt_instructions/`

- `template_image_prompt.txt`
- `template_video_4s_prompt.txt`
- `template_video_6s_prompt.txt`
- `template_video_8s_prompt.txt`
- `template_video_10s_prompt.txt`
- `template_zip_file.txt`
- `template_json_to_srt.txt`

In Project settings → Shared prompt instructions, select a file to edit or load a TXT. Save shared instructions writes all seven files. Open project folder locates them. External UTF-8 file edits are read for new work; conflicting saves require a reload.

For existing projects, select the video with the desired instructions, click Import from selected video, review, then save. Legacy per-video instructions remain available until a shared set is configured. Project files then take precedence for all videos. Existing queued/completed jobs retain their saved instruction snapshots.

GPT-5.6 Sol image batches attach image instructions followed by the separate ZIP template. The default ZIP template preserves the existing output format: one `image_prompts.zip` with numbered UTF-8 TXT files matching the original scene numbers. `{batch_size}` is substituted without changing other braces. Image plus ZIP instructions must fit within 100,000 characters. Video prompts remain text-only. New image ZIP jobs with other models are not enabled; Gemini, Grok and other ChatGPT output adapters will be added separately.

JSON to SRT reads `template_json_to_srt.txt` from the project. Its stage page shows a read-only preview and a link to Project settings. The project editor supplies the existing JSON-to-SRT template and existing ZIP contract as editable defaults. No content-generation instructions are invented for image/video templates.

Navigation labels: Text to Speech (ElevenLabs), Speech to JSON (WhisperX), JSON to SRT. Provider integrations and existing data IDs are unchanged.

Restart Studio after updating. No Chrome extension update is required.
