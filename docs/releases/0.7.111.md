# Studio 0.7.111 — Creation dialogs and compact row actions

- New Project and New Video open native modal dialogs. Existing forms/handlers are moved, not duplicated. Drafts survive closing, errors appear inside the dialog, and successful creation closes it. Closing is blocked while its submit button is disabled.
- Less-used row actions move into a keyboard-accessible more-actions popover. Original buttons, disabled states and callbacks are retained. Existing search, sorting, selection and keyed updates continue to work. Native popovers escape the table's scroll clipping.
- Prompt to Media previews use a larger modal with Previous/Next navigation through saved results of the same media type in the current filtered scenes. Closing or changing video invalidates pending preview requests; no late request reopens the viewer. Object URLs are revoked when the preview closes.
- Job Details / log opens a readable popup with Copy log (or selection for manual copying when clipboard permission is unavailable). Errors remain visible in status cells; popups only open on user action.
- Long prompt/instruction editing and project/video settings remain side panels. Existing delete, regenerate and paid-generation confirmations remain intact.
- Includes the table workspace from 0.7.110. Restart Studio after replacing the complete source. Extensions remain ChatGPT 1.15.0 and Google Flow 0.6.4.
