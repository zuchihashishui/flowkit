# Studio 0.7.98

Generate selected scenes now validates selection and saved settings, confirms generation, opens the saved project Google Flow URL through Electron, then performs preflight and enqueues media jobs. Previously tab opening was deferred to extension generation, which preflight could prevent from ever being reached. Opening the page does not submit generation. Opening errors and changed video context stop submission visibly. Extension connection is still required and checked; no protection is bypassed.

Restart Electron Studio and backend. The default browser used by Electron must have the Google Flow Bridge installed. Extension generation retains its existing project-specific binding logic.
