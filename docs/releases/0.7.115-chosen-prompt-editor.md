# Studio 0.7.115 — SRT to Prompt chosen-row editor

Click Prompt for chosen row type in SRT to Prompt to view and edit the complete Image or Video prompt selected by that row's Type. The popup uses the same scrollable editor styling as Prompt to Media, with Save prompt and Cancel. Saving creates a new concept version and preserves the other prompt, title and description. It keeps unsaved row-type choices, table selection and scroll position, and leaves drafts intact during status refresh or save failure.

Existing scene/source edits must be saved or discarded before saving the prompt. The popup checks the active project/video and current concept before submission. Changing project/video or closing a dirty popup asks before discarding edits.
