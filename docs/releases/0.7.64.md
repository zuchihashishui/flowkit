# Studio 0.7.64 / ChatGPT Bridge 1.11.1

Sửa chế độ Text to Prompt của v0.7.63 theo yêu cầu.

| Chức năng | Số tab | Chế độ | Temporary Chat |
| --- | --- | --- | --- |
| Text to Prompt: SRT + TXT | 3 tab riêng | Chat | Bật |
| JSON → SRT | 1 tab riêng | Work | Tắt |

Text to Prompt chọn Chat rồi bật và xác nhận Temporary Chat trước khi gửi. Cả 3 tab tự mở và bind như trước. Trong mỗi hội thoại tạm thời, lượt đầu gửi TXT + mục SRT; các lượt sau chỉ gửi nội dung SRT và chờ câu trả lời hoàn tất. Không bật/tắt Temporary hoặc tạo hội thoại mới giữa các mục khi hội thoại vẫn còn nguyên.

Với SRT + TXT, Studio sử dụng địa chỉ ChatGPT home của project; hướng dẫn đến từ TXT, không dùng Custom GPT Image/Video URL cũ. Tab JSON → SRT vẫn nhận JSON ở Work, Temporary OFF, và độc lập với ba tab văn bản.

Temporary Chat có thể giữ nguyên URL sau khi tải lại hoặc đổi hội thoại. Bridge kiểm tra trạng thái trong trang và câu trả lời đã xác nhận gần nhất để nhận biết hội thoại còn giữ TXT; nếu mất ngữ cảnh, nó nạp lại hướng dẫn trước mục tiếp theo. Nếu Temporary không bật được hoặc thay đổi ngay trước khi gửi, dòng được báo lỗi để kiểm tra, không tự chuyển sang Chat thường.

## Cập nhật

1. Đóng Studio và backend/gateway cũ; cập nhật mã nguồn từ ZIP này, giữ dữ liệu/output hiện có.
2. Reload `extensions/chatgpt` ở `chrome://extensions`, kiểm tra phiên bản **1.11.1**.
3. Làm mới các tab đã nạp content script cũ và khởi động lại Studio. Chrome cần đăng nhập ChatGPT, extension bật.

## Verification

Automated tests cover 200 rows on three Temporary conversations with exactly one TXT prefix per tab, same-URL reload detection, rejection when Temporary switches off, fresh in-page memory after reload, and three Chat/Temporary jobs running alongside one Work/regular SRT job. Gateway rejects regular Chat or Custom GPT destinations for the new TXT session contract. Existing SRT prepare/download/stop tests remain in the targeted checks.

Tests simulate ChatGPT pages and responses; no live signed-in Chrome run was performed. The previously documented 13 unrelated baseline desktop test failures in v0.7.62/v0.7.63 are outside this fix.
