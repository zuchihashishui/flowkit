# Studio 0.7.112 — Per-video instruction files

- SRT to Prompt automatically reads UTF-8 TXT instructions from the active video's `output/projects/<project--id>/<video--id>/prompts/` directory, including before the first SRT import. Filenames: `prompt_instructions_image.txt`, `prompt_instructions_video_4s.txt`, `prompt_instructions_video_6s.txt`, `prompt_instructions_video_8s.txt`, `prompt_instructions_video_10s.txt`. The existing `prompt_instructions_video-10s.txt` spelling is accepted; the underscore filename takes priority.
- The UI displays the exact directory and Auto-loaded labels. Opening or refreshing the view picks up disk changes for folder-bound instructions. Uploaded/edited instructions and explicit removals take priority; unsaved UI edits survive background refresh. Use folder returns a saved manual slot to automatic loading.
- Missing, empty, oversized, invalid UTF-8 or unsafe linked files produce visible warnings. A missing folder-bound instruction cannot silently fall back to stale image instructions. Files are read only; the organizer does not overwrite them.
- Queued jobs freeze instruction content, so later disk edits cannot change a running batch. Video rows still use the duration bucket and one TXT attachment per row; the image phase retains its existing batching behavior.
- Audited output ownership: new narration, transcription, subtitle, prompt and scene-media jobs resolve their owning project/video directory; existing legacy jobs retain original paths and the organizer copies their durable files into the video directory. Downstream source lists use database ownership and explicit source IDs, not filename guesses. Dropping arbitrary audio/SRT/media files into a folder does not register them automatically. Existing handoff/import controls register those sources without silently replacing edited scenes or starting generation.
- Includes the table layout, creation dialogs, media preview and log popups from 0.7.110–0.7.111. No extension update is required for this change.

Validation: 124 UI/IPC tests and 67 backend tests passed for storyboard, folder mapping, ownership, handoffs and instruction loading. JavaScript syntax checks passed. One known pre-existing history fixture test was excluded (documented in 0.7.110). Live Windows Electron rendering and provider generation were not exercised.

Install: close Studio, replace application source from this ZIP, then restart. Keep existing `.env`, databases and output folders. In SRT to Prompt, expand SRT source & prompt instructions to see the exact prompts directory.
