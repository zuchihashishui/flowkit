# Studio 0.7.60 / ChatGPT Bridge 1.10.0
New SRT jobs send the original selected JSON bytes and the prompt shown in Studio. The hidden boundary-only instruction is removed for new UI/API jobs. Optional Check transcript no longer gates submission. Existing queued boundary jobs keep their original behavior.

After a completed ChatGPT answer, the extension clicks the returned .srt link and waits for Chrome to finish the download. Chrome's original stays under its configured Downloads folder at flowkit-chatgpt/<token>/subtitles.srt. Studio copies the downloaded bytes to output/srt/<job-id>/subtitles.srt, retaining project/video ownership, and stores the answer (statistics and caveats) in response.txt and download metadata in download.json.

The worker closes only after successful save acknowledgment. Failed or interrupted downloads, missing links and invalid SRT keep the tab available. No automatic prompt retry occurs. Multiple distinct SRT links produce an explicit error rather than selecting an arbitrary file.

## Upgrade and use
1. Replace the complete source and restart Studio, backend and gateway.
2. Reload extensions/chatgpt in Chrome. Accept its new **Downloads** permission; confirm version **1.10.0** and Bridge ON.
3. Open SRT. Choose JSON and review the prompt. The supplied template now asks for an actual downloadable SRT file. The exact previous built-in boundary template is upgraded; custom prompts remain unchanged. Use **Use JSON → SRT file template** if a custom prompt still requests boundary IDs.
4. Click Create SRT. Studio waits for response completion, downloads and saves the file. Use Save SRT as… to export another copy.

Browser and backend must run on the same machine with access to Chrome's download folder. Custom Chrome download folders are supported; a Save As dialog must be completed for downloading to finish. The download wait is up to 120 seconds, separately from ChatGPT's response timeout.

Only basic UTF-8/SRT syntax, sequential cue numbering and non-overlap are verified on the downloaded file. Studio does not certify source coverage or full audio duration. Any known duration should be included in your prompt; the separate duration field is for optional local transcript analysis.

## Verification
Automated tests cover original JSON/prompt transport, final-answer file detection, missing links, download failure, authenticated worker routing, native download completion, gateway metadata forwarding, saving before acknowledgment and keeping original browser files. Live signed-in ChatGPT verification remains necessary in the user's Chrome session.
