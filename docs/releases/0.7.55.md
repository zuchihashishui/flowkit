# Studio 0.7.55 — Production workspace

This release keeps **one project → many videos**. Shared URLs and production defaults belong to the project; sources, scenes, prompts, generated media and render jobs belong to a video. Electron still requires you to start each stage yourself.

## What changed

| Area | New behavior |
| --- | --- |
| Project dashboard | See every video's narration, transcript, SRT, prompts, images/clips and final-render progress. Open the next stage without starting it. |
| Preflight | Check saved destinations, extension connectivity, source ownership, required inputs, local tools and storage before submitting. Missing credit text remains informational. |
| Recovery center | Find interrupted and uncertain jobs. Recover saved downloads or resume cached renders where supported; uncertain paid requests are never resent automatically. Failed/interrupted WhisperX jobs have an explicit local retry. |
| Project / video settings | Save shared TTS, WhisperX, media, SRT and assembly defaults. Override individual fields for a video. Jobs retain their submitted settings. |
| Stage forms | Keep option edits and narration drafts per video. **Apply video defaults to stage forms** resets option edits while retaining narration text. |
| Scene Board | Inspect timed SRT text, both prompt types, current media thumbnails and statuses. Filter missing/failed work and retry selected failures without recreating successful scenes. |
| Project tools | Duplicate configuration into a new local project, create database-only or media-inclusive backups, export ZIPs and restore into a new data folder. |
| CLI | Run the same backend stages from a manifest. Default: one stage then pause. Explicit `--continuous` proceeds between stages; atomic checkpoints support resume and uncertain-submission review. |

## Still-image zoom

In **Merge Audio + SRT + Image/Video**, choose **Image motion**:

- **None** — default; existing still-image behavior.
- **Zoom in** — a gradual centered zoom over each image scene.
- **Zoom out** — the reverse motion.

Motion applies to still images, including image scenes in a mixed image/video timeline. Video clips retain their own motion. Scene frame counts, SRT boundaries and narration timing are unchanged. Choose the setting directly on the assembly form, inherit it from the project, or override it for one video. Existing render jobs retain their original option.

## Update

1. Close Studio and its backend. Keep existing databases and `output` media.
2. Replace application source with the complete release, including `agent`, `desktop`, `scripts` and documentation.
3. Launch `start_desktop.bat` normally. The database migration adds video-settings storage without replacing existing records.
4. Open **Project**, select your project/video, and save shared production settings. Review inherited values before starting work.

No extension code changed in this release. Keep the extensions from the working 0.7.54 release. An old backend cannot save the new production settings or silently ignore a requested zoom effect.

Backups require queued/active work to finish or be cancelled. Review-required work can remain. Restore uses a **new folder**, never an in-place database overwrite. Close the current Studio/backend, then follow the returned launch instructions to use restored data. Browser sessions and model installations are not included in backups.
